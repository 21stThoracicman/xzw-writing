# ✍️ 考研英语（一）小作文 · 填空成文与智能批改（周思成 / 王晶婷 双体系）

按年份预匹配模板 → 填空式成文 → 四维度自动评分 + DeepSeek AI 实时点评。

## ✨ 功能

- **17 年真题全覆盖**（2010–2026 英语一小作文），**双体系并行**：
  - **周思成体系**：体裁（notice/email/letter）× 主体段类型（建议/介绍/原因/活动/招募），**齐头式**，小标题式主体
  - **王晶婷体系**："渐渐感动"（建/介/感/动，W1–W8 模板），**缩进式**，三点式主体；通知为标题居中＋日期靠右
- **填空式成文**：逐段选择句型，候选来自三层——本模板指定 → 同类其他句型（讲义）→ 可通用的其他句型；
  主体段还可"＋ 再加一句"
- **版式真实还原**（不是一坨连在一起）：
  - 周思成：齐头式顶格、**段间空行**，Notice 标题行顶格，主体可选英文小标题（Time and Venue / Theme and Highlights），
    建议/理由类三层自动合并为一段（First… Second… Finally…），落款 `Best regards,` + `Li Ming`，通知只署名
  - 王晶婷：称呼顶格、正文首行缩进、通知标题居中＋日期靠右、落款右下两行
  - 预览可开「👁 显示/隐藏格式标记」，直接看到"顶格/缩进/居中/靠右/空行"落在哪里
  - 「📄 复制全文」「💾 下载 TXT」拿到排好版的成文，粘进 Word 段落与空行都在
- **选项不再固定死**：
  - 讲义里的 `A / B / C` 二选一写法在构建时被**拆成独立句型**（133 条 → 159 个可选句子）
  - 每段槽位下方是**推荐替换词条**，点一下即用（不用手打，也不必只用讲义原词）
  - 每段都有 **🤖 AI 帮我想 3 句**：按本题题干 + 你已填好的具体信息现场生成 3 个新句型
  - 下拉框里还有 **✍️ 自己写（自由输入）**：完全自己写，照样按体系排版、照样参与评分
- **参考答案**：一键填入两位老师各自体系的完整答案（**17 年 × 2 套 = 34 篇**）
- **实时预览**：含字数统计与待填提示
- **四维度规则评分**：内容 3.5 / 结构 2.5 / 语言 3.0 / 格式 1.0，并映射王晶婷**五档定档**
- **🤖 AI 智能评价（DeepSeek）**：逐句纠错、重新打分定档、亮点提炼、高分升级句式、重写建议
- 自动校验：拼写、中式表达、专有名词大小写、标点、Notice 标题、署名、字数区间、残留斜杠备选、冠词重复

## 🚀 使用方式

1. 双击 `考研小作文写作.html`（本地使用，除 AI 功能外无需联网）
2. 首页选年份 → 写作页可随时切换体系 → 逐段填空 → 规则评分 / AI 智能评价
3. 用 AI 评价或 AI 造句需填一次 DeepSeek API Key（点「🔑 AI 设置」），Key 只存在你自己的浏览器
