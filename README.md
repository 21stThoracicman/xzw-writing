# ✍️ 考研英语（一）小作文 · 填空成文与智能批改（周思成 / 王晶婷 双体系）

按年份预匹配模板 → 填空式成文 → 四维度自动评分 + DeepSeek AI 实时点评。

## ✨ 功能

- **17 年真题全覆盖**（2010–2026 英语一小作文），**双体系并行**：
  - **周思成体系**：体裁（notice/email/letter）× 主体段类型（建议/介绍/原因/活动/招募），**齐头式**，小标题式主体
  - **王晶婷体系**："渐渐感动"（建/介/感/动，W1–W8 模板），**缩进式**，三点式主体；通知为标题居中＋日期靠右
- **题目区直接用真题原题，中英文对照**（不是转述）：
  - 左栏「英文原题」：2010–2026 英语（一）Part A 真题原文（含 Directions、字数要求、署名要求），抽取自真题 PDF，未改动一字
  - 右栏「中文对照」：对应中文翻译，左右并排；窗口变窄自动变上下排列
  - 下方另附讲义提炼的中文「题目要求」清单，用于逐条自检
- **填空式成文**：逐段选择句型，候选来自三层——本模板指定 → 同类其他句型（讲义）→ 可通用的其他句型；
  主体段还可"＋ 再加一句"
- **版式真实还原**（不是一坨连在一起）：
  - 周思成：齐头式顶格、**段间空行**，Notice 标题行顶格，主体可选英文小标题（Time and Venue / Theme and Highlights），
    建议/理由类三层自动合并为一段（First… Second… Finally…），落款 `Best regards,` + `Li Ming`，通知只署名
  - 王晶婷：称呼顶格、正文首行缩进、通知标题居中＋日期靠右、落款右下两行
  - 预览可开「👁 显示/隐藏格式标记」，直接看到"顶格/缩进/居中/靠右/空行"落在哪里
  - 「📄 复制全文」「💾 下载 TXT」拿到排好版的成文，粘进 Word 段落与空行都在
- **任何段都能删、也都能恢复**：
  - 每段有「🗑 删除本段」（含称呼、落款、标题、正文段），每句有「🗑 删除这句」（**主句也能删**）
  - 删掉的段标「已删」并变灰，成文里不出现；点「↩ 恢复默认」原样回来
  - 删段按"本段不计入"处理，不会被算成"没写完"
- **署名人按真题原题预填、可随时改**：
  - 不同题目署名人不同（如 2010 年原题要求署 `Postgraduates' Association`，不是 Li Ming），
    进入写作页时已按原题自动填好，并在下方写明原题对署名的要求
  - 署名段有「署名人」输入框，外加 `Li Ming` / `Postgraduates' Association` / `The Student Union` 一键切换；
    改完成文（含王晶婷体系的 `Yours sincerely,` 落款）跟着变
- **选项不再固定死**：
  - 讲义里的 `A / B / C` 二选一写法在构建时被**拆成独立句型**（133 条 → 159 个可选句子）
  - 每段槽位下方是**推荐替换词条**，点一下即用（不用手打，也不必只用讲义原词）
  - 每段都有 **🤖 AI 帮我想 3 句**：按本题题干 + 你已填好的具体信息现场生成 3 个新句型
  - 下拉框里还有 **✍️ 自己写（自由输入）**：完全自己写，照样按体系排版、照样参与评分
- **参考答案**：一键填入两位老师各自体系的完整答案（**17 年 × 2 套 = 34 篇**）
- **实时预览**：含字数统计与待填提示
- **四维度规则评分**：内容 3.5 / 结构 2.5 / 语言 3.0 / 格式 1.0，并映射王晶婷**五档定档**
- **🤖 AI 智能评价（DeepSeek）**：逐句纠错、重新打分定档、亮点提炼、高分升级句式、重写建议
- 自动校验：拼写、中式表达、专有名词大小写、标点、Notice 标题、署名、字数区间、残留斜杠备选、冠词重复
- **🔍 语法与用法逐条纠正（离线，74 条规则）**：
  - 覆盖冠词、主谓一致、动词形式与时态、介词与固定搭配、名词单复数、句式结构、
    中式表达、标点与大小写、流水句
  - 每条给"原文片段（划掉）→ 应写成（可直接照抄）→ 中文原因"，可一键复制修改清单
  - 已用讲义 42 篇范文校验 **0 误报**，33 个常见错误句 **100% 检出**
- **评分按真实阅卷权重标定，扣分明细全部公开**：
  - 语言分从基线 1.95 往上挣：字数、衔接词、句式结构、词汇丰富度、自写句零错误都加分；每处语法硬伤 −0.18
  - **模板化上限**：全文都是讲义模板句时语言分最高 2.25/3.0 —— 模板作文通常在 7.0–8.5；
    写几句自己的（✍️ 自由句 / 🤖 AI 句）即可解开上限
  - 结果页列出"语言分是怎么算出来的"每一步，不是黑箱
- **规则评分 vs AI 评分对照**：AI 评价卡片里会同时给出两个分数与差值原因，
  说清"规则只能看可量化项、AI 还会看扣题度与地道性"，避免只看一个数字的误判
